INTERACTIVE TUTORIAL准备

选择操作方式

请选择鼠标或摄像头手势模式。

鼠标

轻触 / 挤压：点按或拖动水母。

生小水母：从伞盖边缘按住，向外拉，再松开。

吹气泡：点击水母外的空白海水。

摄像头手势

逗水母：用一根食指靠近它。

挤压 / 生小水母：拇指与食指在母体上捏合；拉向边缘外，再张开。

释放气泡：在母体外的空白海水握拳，再张开手掌。

等待选择输入模式

摄像头不可用时可随时切换回鼠标。

ABOUT THE WORK

柔软，也是一种回应。

《水母之森》是一件浏览器交互作品。母水母的轮廓由 72 个弹簧节点组成，因此触碰会留在局部，而不是缩放整只角色。

普通触摸只产生表情与回弹；从伞盖任意边缘向外拉动，才会诞生一只有自己性格的小水母。
